# NokiaN76_BluetoothFix
btaccserver patch to control volume via AVRCP
> To install the patch, you need an unlocked phone with full access to the file system.(RomPatcher Open4All)
Send all files to you phone(btrcc.dll; btrcc.rsc; btaccserver.exe)
## Move the files to this path:
### btrcc.dll and btaccserver.exe to C:/sys/bin

### btrcc.rsc to C:/resource/plugins
> If the "plugins" folder does not exist, create it.
And reboot you phone, enjoy!
